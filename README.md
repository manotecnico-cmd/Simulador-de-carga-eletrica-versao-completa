# Simulador de Carga Elétrica – Versão Completa

Ferramenta para dimensionamento técnico de cargas elétricas com aplicação prática em campo.

Inclui:
- Cálculo com margem de segurança ajustada
- Consideração de partida de motores
- Análise de simultaneidade de cargas
- Geração de relatório em PDF
- Inserção de dados do cliente

---

## 📊 Aplicação

Indicado para:
- Geradores de energia
- Obras e construção civil
- Eventos
- Instalações elétricas em geral
